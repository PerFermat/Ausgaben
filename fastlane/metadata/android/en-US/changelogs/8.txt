SMB/Samba is a lot more robust: shares with SMB3 encryption, DFS and purely anonymous shares now work, and traffic is signed if the server requires it. Shares without a password work without tricks - just leave the password field empty, even with a user name filled in. If the configured port does not answer, the app also tries the default port 445 and corrects the address. New: "Check connection (diagnostics)" in the settings and in the first-start wizard. It walks the whole chain (connect, negotiate, log in, shares, read folder, write permission, file) and shows the result, the duration and, on failure, the status code for every step - including whether the target folder is writable at all. The report can be copied and contains neither the password nor the user name. Error messages now name the real cause instead of a blanket "Server not reachable".
